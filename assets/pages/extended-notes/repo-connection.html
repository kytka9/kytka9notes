Prepojenie repa

Ako zistiť prepojenie s repozitárom

Pre zobrazenie adresy vzdialeného repozitára (remote), na ktorý je projekt napojený, spusti príkaz:

git remote -v
  • Ak projekt JE prepojený: Vypíšu sa URL adresy s označením origin (pre fetch aj push).
  • Ak projekt NIE JE prepojený: Príkaz nevráti žiadny výstup.
  • Ak adresár vôbec nie je Git repozitárom: Zobrazí sa chybová hláška fatal: not a git repository.

Ako odstrániť prepojenie na repozitár

Máš dve možnosti podľa toho, čo presne chceš dosiahnuť:

A: Odpojiť len vzdialený GitHub repozitár (ponechá lokálnu Git históriu): Týmto príkazom zmažeš iba prepojenie na online server (GitHub). Tvoj lokálny kód aj história commitov zostanú nedotknuté.

git remote remove origin

B: Úplne zrušiť Git v projekte (vymaže celú Git históriu): Ak chceš z projektu odstrániť akúkoľvek stopu Gitu a spraviť z neho obyčajný priečinok, stačí vymazať skrytý priečinok .git

rm -rf .git

Ako vytvoriť prepojenie na existujúci repozitár

1. prejdi do priečinka projektu: cd nazov-projektu

2. Ak projekt ešte nie je Git repozitár, inicializuj Git: git init (Tým sa v projekte vytvorí skrytý priečinok .git, v ktorom Git uchováva históriu a nastavenia repozitára.)

3. Pridaj vzdialený repozitár:

git remote add origin https://github.com/username/repositary.git

origin je názov vzdialeného repozitára, je to bežný štandardný názov, ale technicky môžeš použiť aj iný

4. Skontroluj, či sa prepojenie podarilo:

git remote -v

Ako zmeniť prepojenie na iný repozitár

Ak je projekt už napojený na nejaký repozitár, ale chceš ho napojiť na iný:

Možnosť A: zmeniť URL existujúceho remote

git remote set-url origin https://github.com/username/new-repositary.git

Výhoda je, že zostane zachovaná lokálna Git história aj všetky ostatné nastavenia.

Možnosť B: odstrániť starý remote a pridať nový

git remote remove origin

potom:

git remote add origin https://github.com/username/new-repositary.git
