Prepojenie repa

Ako zistiť prepojenie s repozitárom

Pre zobrazenie adresy vzdialeného repozitára (remote), na ktorý je projekt napojený, spusti príkaz:

git remote -v
  • Ak projekt JE prepojený: Vypíšu sa URL adresy s označením origin (pre fetch aj push).
  • Ak projekt NIE JE prepojený: Príkaz nevráti žiadny výstup.
  • Ak adresár vôbec nie je Git repozitárom: Zobrazí sa chybová hláška fatal: not a git repository.

Ako odstrániť prepojenie na repozitár

Máš dve možnosti podľa toho, čo presne chceš dosiahnuť:

A: Odpojiť len vzdialený GitHub repozitár (ponechá lokálnu Git históriu): Týmto príkazom zmažeš iba prepojenie na online server (GitHub). Tvoj lokálny kód aj história commitov zostanú nedotknuté.

git remote remove origin

B: Úplne zrušiť Git v projekte (vymaže celú Git históriu): Ak chceš z projektu odstrániť akúkoľvek stopu Gitu a spraviť z neho obyčajný priečinok, stačí vymazať skrytý priečinok .git

rm -rf .git
