Vytvorenie gh repa

Vytvorenie a naplnenie repozitára na github CEZ TERMINÁL

1. Prejdi do priečinka s tvojím projektom

cd ~/Documents/moj-projekt

2. Inicializuj Git repozitár

git init

3. Pridaj súbory a urob prvý commit

git add .
git commit -m "coment commit"

4. Vytvor nový repozitár na GitHube (potrebné GitHubCLI: gh —version)

gh repo create nazov-tvojho-repa --public --source=. --remote=nazov-aliasu-repa --push

Tento príkaz:

  • vytvorí repozitár na GitHube
  • pridá vzdialený alias
  • a rovno pushne tvoj projekt

5. Overenie

git remote -v

Správny výstup, niečo ako:

alias-repa https://github.com/tvojemeno/nazov-tvojho-repa.git (fetch)
alias-repa https://github.com/tvojemeno/nazov-tvojho-repa.git (push)
